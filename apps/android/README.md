# Oby for Android and Wear OS

Not on the roadmap yet.

This folder will hold one Gradle project with two modules: `app/` for Android phones and `wear/` for Wear OS. They share code the way the iPhone and Apple Watch apps share `apps/Oby.xcodeproj`. Oby's face comes from [`Character/`](../../Character/README.md), shown in a `WebView`.
