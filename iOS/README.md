# Oby for iPhone

Coming in F15 ([#19](https://github.com/deskree-inc/oby/issues/19)).

The iPhone app will be a target in `Oby.xcodeproj`, next to the Mac app, so the two share Swift code. It shows Oby's face from [`Character/`](../Character/README.md) in a web view, like the Mac app does.

A starting point: `Apps/OberonMobile.swiftpm` in [well-prado/oberon-app](https://github.com/well-prado/oberon-app).
